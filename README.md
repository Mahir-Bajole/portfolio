# Portfolio

Personal portfolio website of **Mahir Bajole** — Backend Engineer.

A single-file React component (`Portfolio.jsx`) featuring projects, experience, skills, education and contact sections.

## Usage

Drop `Portfolio.jsx` into any React app (e.g. Vite or Create React App) and render it:

```jsx
import Portfolio from "./Portfolio";

export default function App() {
  return <Portfolio />;
}
```

The component is self-contained: styles are injected via an inline `<style>` tag, so no extra CSS setup is required.
